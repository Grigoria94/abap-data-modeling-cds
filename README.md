# abap-data-modeling-cds

# Data Modelling in ABAP Dictionary and ABAP Core Data Services

This repository contains my progress and exercises for ABAP Data Modelling on SAP S/4HANA. 
The code covers fundamental concepts of the ABAP Dictionary and the modern CDS (Core Data Services) approach.

## Topics Covered

Based on the course curriculum, this project includes:

### Unit 1: Exploring Data Modeling in ABAP
* Analysis of Dictionary and CDS Objects.

### Unit 2: Creating Database Tables
* Creation of Domains and Data Elements.
* Database Table Definitions.
* Handling changes to Database Tables.

### Unit 3: Defining Global Data Types
* Dictionary Structures.
* Dictionary Table Types.

### Unit 4: Defining Basic CDS Views
* Defining Basic CDS Views.
* Using Annotations in Data Definitions.
* Defining "View on a View" scenarios.

## 🛠️ Tools Used
* **Eclipse IDE** with ABAP Development Tools (ADT).
* **abapGit** for version control.
* **SAP S/4HANA** System.
